📘 Student Marks Analyzer 
A simple Python program that analyzes students’ marks and generates useful statistics such as:
✅ Student-wise average marks
✅ Class topper (highest total marks)
✅ Subject-wise average marks
This project demonstrates basic Python concepts like dictionaries, loops, data processing, and formatted output.

Features
✔ Student Average Calculation 
✔ Find the Topper
✔ Subject-wise Average

Requirements : Python 3.x

📝 Explanation
🔹 Marks Dictionary:
    Stores students’ marks 
🔹 Student Averages:
For each student:
    Add marks
    Divide by number of subjects
    Print formatted average
🔹 Finding the Topper:
The program loops through all students and tracks:
    Highest total marks
    Name of the topper
🔹 Subject-wise Average:
For each subject:
    Sum scores of all students
    Divide by total students
